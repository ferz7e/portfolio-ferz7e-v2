Descripción

Desarrollo de sitio web institucional para Erco Seguridad, orientado a la presentación de servicios, trayectoria corporativa e industrias atendidas.

La solución incorpora diseño responsive, formularios integrados con API, optimización de rendimiento, carga diferida de recursos y una estrategia SEO completa mediante metadata por página, Open Graph, JSON-LD, sitemap y robots.txt.

Stack

  • Frontend: React + TypeScript + Tailwind
  • Backend: Node.js + TypeScript
  • Animaciones: Motion
  • Infra: self-host en servidor propio + Docker
