Descripción

Es un sistema integral de gestión para empresas de seguridad privada, donde el producto controla toda la operación de personal y servicios: autenticación de usuarios por rol, alta de clientes y guardias, planificación de objetivos y turnos semanales, asignación y control de asistencia con QR, seguimiento de patrullas y checkpoints, gestión de incidencias con advertencias y sanciones, administración de indisponibilidades, liquidaciones y tablero de resumen para decidir desde un solo lugar.

Stack

  • Frontend: React + Typescript + Tailwind
  • Backend: NestJS + Typescript
  • Base de datos: Prisma ORM + PostgreSQL
  • Infra: self-host en servidor propio + Docker
