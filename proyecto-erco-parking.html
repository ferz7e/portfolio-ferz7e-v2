Descripción

Sistema desarrollado para Erco Seguridad con el objetivo de gestionar y controlar el acceso a cocheras dentro de edificios y complejos residenciales.

La solución permite validar permisos de estacionamiento, realizar consultas por patente, cochera o código QR, registrar incidencias y facilitar la operación diaria desde dispositivos ubicados en garita. La solución contempla además un portal para propietarios, donde podrán consultar cocheras, vehículos y permisos asociados.

Stack

  • Frontend: React + TypeScript + Tailwind
  • Backend: NestJS + TypeScript
  • Base de datos: Prisma ORM + PostgreSQL
  • Infra: self-host en servidor propio + Docker
