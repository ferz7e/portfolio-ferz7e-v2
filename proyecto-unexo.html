Descripción

Lanzé una plataforma digital que validó interés inicial del mercado en menos de una semana, alcanzando más de 60 usuarios y 3 anunciantes activos. Desarrollé el producto de punta a punta con autenticación propia (registro, verificación por email y recuperación de contraseña), arquitectura frontend por roles (user, admin, founder) con renderizado condicional y funcionalidades específicas, además de módulos de publicaciones, interacción con contenido, gestión de cuenta y panel personal. También incorporé búsqueda con filtros en cascada, paginación y navegación optimizada, y herramientas administrativas para gestión de usuarios, anuncios, reportes, logs y métricas por rol.

Stack

  • Frontend: React + TypeScript + Tailwind + Chakra UI
  • Backend: Express + TypeScript
  • Base de datos: Prisma ORM + PostgreSQL
  • Infra: self-host en servidor propio + Docker
