Descripción

Unexo fue una red social universitaria desarrollada y lanzada de forma independiente con el objetivo de conectar estudiantes, organizaciones y anunciantes dentro del entorno académico.

Desarrollé el producto de punta a punta, incluyendo arquitectura frontend y backend, autenticación de usuarios, gestión de roles, sistema de publicaciones, búsqueda avanzada, panel administrativo y herramientas de moderación. El proyecto alcanzó más de 60 usuarios registrados y 3 anunciantes activos durante su primera semana, validando interés inicial por parte del mercado objetivo.

Stack

  • Frontend: React + TypeScript + Tailwind + Chakra UI
  • Backend: Express + TypeScript
  • Base de datos: Prisma ORM + PostgreSQL
  • Infra: self-host en servidor propio + Docker
