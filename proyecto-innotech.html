Descripción

Sitio web corporativo desarrollado para Innotech con el objetivo de comunicar sus servicios tecnológicos y fortalecer su presencia digital.

La solución incluye una experiencia responsive orientada a la captación de potenciales clientes, con una estructura de contenidos enfocada en la presentación de servicios, diferenciadores de negocio y canales de contacto. Se implementaron mejoras de SEO técnico, optimización de carga de recursos y estrategias de rendimiento para mejorar visibilidad y experiencia de usuario.

Stack

  • Frontend: React + TypeScript + Tailwind
  • Backend: NestJS + TypeScript
  • Base de datos: Prisma ORM + SQLite
  • Infra: hosting en servidor de la empresa
