Descripción

Innotech Site es un sitio web corporativo desarrollado con una interfaz moderna, responsive y orientada a comunicar servicios tecnológicos de forma clara y profesional. El proyecto combina una estética limpia con secciones comerciales bien estructuradas para presentar la propuesta de valor de la marca y facilitar el contacto con potenciales clientes, incluyendo mejoras de SEO técnico y lazy load para optimizar visibilidad y performance.

Stack

  • Frontend: React + Tailwind + TypeScript
  • Backend: NestJS + TypeScript
  • Base de datos: Prisma ORM + SQLite
  • Infra: hosting en servidor de la empresa
